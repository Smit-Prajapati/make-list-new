📝 How to Customize

All data is in data.js. To add/modify:

  • New page: Add object to pages array
  • New tab: Add to tabs array in page
  • New item: Add to items array with tabId
  • Gujarati name: Set gujarati: "ગુજરાતી" field
  • No tabs: Set tabs: [] (shows all items)

📂 File Structure

  • data.js — All pages, tabs, items (single source of truth)
  • index.html + index.js — Home page
  • list.html + script.js — List page with tabs
  • style.css — All styling
  • README.md — Full documentation
